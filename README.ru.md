# ProjectorCal — бесплатная калибровка проекторов Vidda и Hisense

**Откалибруйте проектор Vidda / Hisense сами — колориметр, флешка и один вечер.**
ProjectorCal измеряет изображение и говорит, **какие именно значения поставить в меню** (баланс белого Gain/Offset,
точки гаммы, CMS), а после каждого прогона узнаёт, как реагирует *ваш* проектор, и уточняет следующий совет.

Подходит для Vidda C3S (проверено), C3 / C3 Pro / C3 Ultra, Hisense C2 / C2 Pro / C2 Ultra, C1, ультракороткофокусных
PX1 / PX2 / PX3 и лазерных ТВ Hisense. Работает с любым колориметром или спектрометром, который поддерживает
ArgyllCMS: i1Display Pro, Calibrite Display Plus HL / ColorChecker Display, ColorMunki Display, Datacolor SpyderX /
Spyder5, i1Pro, Klein K10.

Бесплатно, открытый код (MIT). Работает локально в браузере на **Windows, macOS и Linux**, без аккаунтов и телеметрии.
Интерфейс программы — на английском; эта страница — краткое руководство на русском.

## Как это работает

1. **Вносите** текущие значения меню проектора (один раз).
2. **Запускаете одно видео** на проекторе — с флешки или через Plex — и уходите из комнаты (SDR 14 мин).
3. Программа сама распознаёт все 51 патч, проверяет каждый отсчёт и отбрасывает подозрительные (меню на экране,
   кто-то прошёл перед лучом, включили свет, плеер притормозил).
4. Получаете **вердикт с цифрами**: *«Point 6: −11 → −3, Offset R: 0 → −1, Blue Bright: 4 → 5»*.
5. Ставите значения в меню, повторяете прогон. Обычно **3–6 прогонов** до ΔE серого ≈ 1 и гаммы 2.4 на всех ступенях.

## Запуск

* **Windows:** двойной щелчок по `ProjectorCal.cmd` (окно не закрывать, пока идёт калибровка); `Create desktop shortcut.cmd` создаёт ярлык на рабочем столе. Для i1Display / Calibrite / ColorMunki Display драйвер не нужен; для Spyder и i1Pro нужен USB-драйвер ArgyllCMS. Поддержка Windows новая (бета) — напишите, как заработало.
* **macOS:** `ProjectorCal.app` (первый раз — правый клик → «Открыть»).
* **Linux:** `./projectorcal.sh` (`./install-desktop-entry.sh` добавит в меню приложений).

Видеопатчи можно положить в папку `assets` рядом с программой или сразу скопировать папку `patches` на флешку / в Plex.

## Коротко по шагам

1. **Прогрейте проектор 45–60 минут** в режиме Filmmaker. Выключите всё «умное»: динамический контраст, AI, MEMC,
   датчик освещённости.
2. **Колориметр** — по центру экрана, 0,7–1,5 м, чуть ниже луча; не двигать во время сессии. SpyderX прогреть
   10–15 минут; для Calibrite Plus HL один раз запустить Calibrite PROFILER.
3. **Settings** в программе: выберите **модель проектора** и **модель прибора**. Программа сама подскажет, какое
   видео запускать — обычное или *slow* (для медленных приборов). Проверьте **число точек гаммы** (Gamma → Adjust →
   Control Point): 20 точек по 5 %, 10 точек по 10 % или их нет.
4. **Preparation**: *Check again* → прибор найден; *Test reading* на белом патче; замер засветки комнаты.
5. **Full check**: внесите текущие настройки проектора, нажмите **Start SDR** и запустите на проекторе файл, который
   покажет программа (`AUTO/ProjectorCal_AUTO_SDR_v3.mp4` или `..._v3_slow.mp4`).
6. Прочитайте **вердикт**, поставьте значения в меню, нажмите *«I set all this in the menu → save to settings»* и
   повторите прогон, пока программа не скажет, что всё в допуске.

## Какие проекторы поддерживаются

| Модель | Статус | Точки гаммы |
|---|---|---|
| Vidda C3S | ✅ проверено (7 полных прогонов) | 20 × 5 % |
| Vidda C3 / C3 Pro / C3 Ultra | должно работать | 20 × 5 % (предположительно) |
| Hisense / Vidda C2, C2 Pro, C2 Ultra, C2 Max | должно работать | проверьте в меню |
| Hisense / Vidda C1, C1S | должно работать | проверьте в меню |
| Hisense PX1 / PX2 / PX3 (Pro) | должно работать | проверьте в меню |
| Лазерные ТВ Hisense | баланс белого + CMS | обычно нет |
| Любой проектор / ТВ с Gain/Offset и CMS | баланс белого + CMS | 20, 10 или нет |

Программе не нужна база настроек конкретной модели: шаг каждого регулятора (сколько процентов даёт один шаг Gain,
Offset, точки гаммы, CMS) она измеряет на ваших прогонах. Пока шаг не изучен, первое изменение ограничено, так что
незнакомый проектор не «уведёт» далеко.

Если вы откалибровали модель, которой нет в списке проверенных, — [напишите нам](docs/SUPPORTED.md#help-us-verify-your-model),
одного отчёта достаточно.

## Точность на лазерных проекторах

У лазера очень узкий спектр, и заводская калибровка колориметра на нём может ошибаться в абсолютной точке белого и
насыщенных цветах на несколько ΔE. Надёжно измеряются **трекинг серого, гамма и все изменения между прогонами** —
то, ради чего и делается калибровка. Для абсолютной точности используйте спектральную коррекцию `.ccss` для
RGB-лазера (Settings → Correction или Display type).

## Результат на Vidda C3S

С Calibrite Display Plus HL, семь прогонов от заводского Filmmaker: **ΔE2000 серого ≈ 1,0, гамма 2,40 ± 0,02 на
всех ступенях 10–95 %, взвешенный ΔE цвета ≈ 1,7, контраст ≈ 1350:1.** Подробно — в
[разборе (англ.)](docs/case-study/vidda-c3s.md).
